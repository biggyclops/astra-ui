## Purpose

## What Astra is (current, from Master)

Astra is a multi-surface AI operating environment:

- **Astra UI (desktop)** — control-plane web app on Mini-Beast
- **AstraPhone** — iOS companion against the live Astra API
- Shared fleet nodes (Mini-Beast, Hades, Hermes, Talos, Atlas, …) behind that API
