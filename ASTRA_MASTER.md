# Astra Master

## Identity
Astra is the mythic cyberpunk AI interface hosted by Talos. It is not a generic chatbot shell and should remain a calm, observant, cinematic operations environment.

## Visual Rules
- Dark mystical background
- Restrained cyan and ember glow
- Translucent holographic panels
- Desktop-first composition
- Immersive atmosphere over dashboard density
- Smooth motion, spacing, and presence

## Stack
- React
- Vite
- TypeScript
- Tailwind CSS
- Framer Motion
- Zustand
- Future React Three Fiber support

## Current Scope
- Frontend shell architecture only
- No backend logic
- No auth work
- No telemetry API integration

## Shell Model
- Left sidebar
- Center conversation core
- Right context panel
- Atmospheric background layer
- Subtle presence layer

## Working Agreement
- Preserve the Astra identity
- Avoid generic SaaS styling
- Avoid gamer RGB aesthetics
- Keep the shell modular and production-structured
