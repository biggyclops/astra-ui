Add a Settings panel to Astra (left sidebar gear icon).

GOALS
- Settings must be minimal, operator-focused, and lore-true.
- No bloated preferences; only controls that affect Astra behavior or connectivity.
- Persist settings in localStorage now; later swap to DB without changing UI.

LAYOUT
- Page: /settings
- Two-column layout on desktop:
  Left: sections list
  Right: section content
- Sections:
  1) Identity
  2) Nodes & Network
  3) Media Wall
  4) Jobs
  5) Voice (placeholder for later)
  6) About / Diagnostics

SECTION DETAILS
1) Identity
- “Name” field: Astra
- “Tone” dropdown: Calm / Direct / Dry / Friendly (affects UI copy only)
- “Lore Mode” toggle: ON by default
  - When ON: Astra uses operator-style responses (brief summary, checklist, commands)

2) Nodes & Network
- Node Registry (manual for now):
  - list of nodes with name + baseUrl
  - buttons: Add Node, Edit, Remove
  - validation: must be http(s):// URL
- Default Node selection:
  - dropdown for “LLM Node” (Kratos)
  - dropdown for “Render Node” (Hades)
  - dropdown for “Storage Node” (Hermes)
- “Connectivity Test” button:
  - pings each node’s /health endpoint (mock for now)
  - shows status chips: Online / Offline / Unknown
- Safety toggle:
  - “Require approval before running jobs” (ON by default)

3) Media Wall
- “Ambient Loop Mode” default: OFF
- “Max simultaneous videos” slider: 1–12 (default 6)
- “Autoplay on hover” toggle: ON
- “Show labels (IMG/VID)” toggle: ON
- “Default sort” dropdown: Newest / Oldest
- “Default filter” dropdown: All / Videos / Images

4) Jobs
- “Max concurrent jobs” slider (default 1)
- “Auto-open job output in Media Wall” toggle: ON
- “Keep job history” dropdown: 24h / 7d / 30d
- “Stop conditions” text preview (read-only):
  - stop after 5 iterations or destructive actions need approval

5) Voice (placeholder)
- Disabled controls with “Coming soon”
- Toggles shown but locked:
  - Push-to-talk
  - Wake word
  - Voice output
- Notes: Voice will route to Kratos service later

6) About / Diagnostics
- App version, build info
- Buttons:
  - “Export settings” (download JSON)
  - “Import settings” (upload JSON)
  - “Reset settings” (confirm dialog)

IMPLEMENTATION
- Create a typed settings model (shared/settings.ts) and a hook:
  - useSettings() loads/saves localStorage
- Add a small settings icon in sidebar that routes to /settings.
- Keep styling consistent with current dark Astra theme (violet/teal/gold accents, minimal glow).
